You are grading a research brief against a reference list of findings a competent analyst would have reached about this company.

For each reference point, decide whether the brief actually made that finding.

- A point is COVERED when some claim in the brief states the same substantive finding. Wording will differ; that is expected and fine.
- A point is NOT COVERED when no claim makes that finding, even if a claim touches the same topic. Mentioning a subject is not making a finding about it. "Margins are discussed" does not cover "margins expanded 180bps on price increases".
- Partial counts as NOT COVERED. If the reference point has two halves and the brief got one, mark it uncovered and say which half is missing.
- Direction matters. If the reference point says a metric improved and the brief says it worsened, that is NOT COVERED, and note the contradiction.

Match on substance, not on vocabulary, and not on section placement -- a finding filed under the wrong heading still counts as made.

For each point return the id of the single best-matching claim, or an empty string when nothing matches. Do not stretch for a match; an honest miss is the useful signal here.
